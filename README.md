## Publication status

The technical classification memorandum is the controlling document for descriptions of **HADFI**. It characterizes HADFI as an internal project designation and a proposed technical characterization; it does **not** represent an externally recognized classification, an implementation audit, a legal opinion, a regulatory certification, or a safety assurance case. See [`DOCUMENT_CONTROL.md`](DOCUMENT_CONTROL.md) for the authority order and public-claim requirements.

The materials describe intended architecture, governance controls, and evaluation requirements. They do not establish that any component has been deployed, independently tested, certified, or accepted by a court or regulator. Statements about legal, security, privacy, payment, commercial value, or regulatory matters require context-specific qualified review before operational or public reliance. Superseded compiled files and release archives have been excluded from this public repository.

## Integrity

The `releases/` folder contains the complete archive and its SHA-256 checksum. Verify the downloaded archive with:

```bash
sha256sum -c Axiom_Hive_Professional_Document_Archive.zip.sha256
```
